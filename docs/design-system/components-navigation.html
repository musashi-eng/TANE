ナビゲーションコンポーネント

TabGroup・Tab のボックス型タブコンポーネント

TabGroupComponent + TabComponent

セレクター: ui-tab-group + ui-tab  |  ボックス型タブ  |  WAI-ARIA Tabs パターン準拠

基本的なタブ（4タブ構成）

得意先情報

得意先の基本情報（得意先コード、得意先名、担当スタッフ、通知メール設定など）がここに表示されます。

ユーザー管理

得意先に紐づくユーザーの一覧と管理機能がここに表示されます。

納品先管理

納品先の一覧と管理機能がここに表示されます。

商品管理

商品の一覧と管理機能がここに表示されます。

disabledタブ付き

このタブは有効です。中央の「無効なタブ」はクリックできず、キーボードナビゲーションでもスキップされます。

（このパネルは表示されません）

このタブも有効です。矢印キーで移動すると、無効なタブはスキップされます。

2タブ構成

概要タブの内容です。シンプルな2タブ構成の例。

詳細タブの内容です。

API仕様

コンポーネント プロパティ 型 説明
ui-tab-group [(selectedIndex)] number 選択中タブのインデックス（双方向バインディング）
ui-tab [label] string (required) タブのラベルテキスト
ui-tab [disabled] boolean タブの無効状態（デフォルト: false）

キーボード操作

キー 動作
→ 次の有効タブへフォーカス移動（循環）
← 前の有効タブへフォーカス移動（循環）
Home 最初の有効タブへフォーカス移動
End 最後の有効タブへフォーカス移動
Enter / Space フォーカス中のタブを選択

使用例

<ui-tab-group [(selectedIndex)]="activeTab">
  <ui-tab label="得意先情報">
    <app-customer-info [customer]="customer()" />
  </ui-tab>
  <ui-tab label="ユーザー管理">
    <app-customer-users [customerId]="customerId()" />
  </ui-tab>
  <ui-tab label="納品先管理" [disabled]="true">
    <p>後続スペックで実装予定</p>
  </ui-tab>
</ui-tab-group>
